03 · JSON / Sérialisation

Mapping des champs Flutter ↔ Backend

Le backend retourne du snake_case. Flutter utilise json_serializable avec des champs camelCase. Sans configuration explicite, la désérialisation échouera silencieusement.

🚨 Problème critique Exercise.dureeSec tentera de lire "dureeSec" dans le JSON alors que l'API retourne "duree_sec". Idem pour creeLe, commenceLe, utilisateurId, etc. Les objets seront partiellement nuls sans erreur visible.

Exercise creeLe cree_le @JsonKey requis

Session exerciceId exercice_id @JsonKey requis
Session commenceLe commence_le @JsonKey requis
Session termineLe termine_le @JsonKey requis
StartSimulationResponse sessionId session_id @JsonKey requis
StartSimulationResponse exerciseTitle exercise_title @JsonKey requis

UserProgress avgScore avg_score @JsonKey requis

05 · Backend + Flutter

Gestion du Refresh Token

Le backend retourne un access_token (15 min) ET un refresh_token (24h). Flutter ne sauvegarde et n'utilise que l'access token — après 15 minutes, l'utilisateur sera déconnecté sans raison apparente.

Problème actuel auth_service.dart lit uniquement response.data['access_token'] et oublie le refresh_token. L'intercepteur Dio efface le token sur 401 mais ne tente pas de le renouveler.
lib/core/network/api_client.dart — Intercepteur avec auto-refresh Dart 
// Dans AuthService.login() :
final token = response.data['access_token'];
final refreshToken = response.data['refresh_token'];
if (token != null) await _apiClient.saveToken(token);
if (refreshToken != null) await _storage.write(key: 'refresh_token', value: refreshToken);

// Dans l'intercepteur onError de ApiClient :
onError: (DioException e, handler) async {
  if (e.response?.statusCode == 401) {
    final refreshToken = await _storage.read(key: 'refresh_token');
    if (refreshToken != null) {
      try {
        final resp = await Dio().post('$baseUrl/auth/refresh',
          data: {'refresh_token': refreshToken});
        await saveToken(resp.data['access_token']);
        // Rejouer la requête originale
        e.requestOptions.headers['Authorization'] = 'Bearer ${resp.data['access_token']}';
        return handler.resolve(await dio.fetch(e.requestOptions));
      } catch (_) {
        await _storage.deleteAll(); // Session expirée → logout
      }
    }
  }
  return handler.next(e);
},

Endpoint à créer : /scenarios

app/routers/scenarios.py (nouveau fichier) Python 
from fastapi import APIRouter, Depends
from sqlalchemy.ext.asyncio import AsyncSession
from app.data.database import get_db
from app.core.security import get_current_user
from app.models.user import User
from pydantic import BaseModel
from typing import List, Optional
import uuid

router = APIRouter(prefix="/scenarios", tags=["scenarios"])

# Simple stockage en mémoire pour commencer (migrer vers DB ensuite)
_scenarios: dict = {}

class ScenarioCreate(BaseModel):
    role: str
    company: str
    questions: Optional[List[str]] = []

class ScenarioResponse(ScenarioCreate):
    id: str

@router.get("", response_model=List[ScenarioResponse])
async def list_scenarios(user: User = Depends(get_current_user)):
    return [s for s in _scenarios.values() if s['user_id'] == str(user.id)]

@router.post("", response_model=ScenarioResponse, status_code=201)
async def create_scenario(body: ScenarioCreate, user: User = Depends(get_current_user)):
    sid = str(uuid.uuid4())
    scenario = {"id": sid, "user_id": str(user.id), **body.dict()}
    _scenarios[sid] = scenario
    return scenario
07 · Backend · IA

Simulation IA — Streaming SSE

La maquette utilise un stream de réponses IA en temps réel. Le backend a la route prête mais non implémentée. Voici l'implémentation complète avec Claude (Anthropic) ou OpenAI.

app/routers/simulation.py — stream_ai_response (complet) Python 
from fastapi.responses import StreamingResponse
import anthropic  # pip install anthropic
import json

@router.get("/stream/{session_id}")
async def stream_ai_response(
    session_id: UUID,
    current_user: User = Depends(get_current_user),
    db: AsyncSession = Depends(get_db)
):
    """Streaming SSE de la réponse IA — compatible EventSource (web) et Dio (mobile)"""

    result = await db.execute(
        select(Session).join(Exercice).where(
            (Session.id == session_id) &
            (Session.utilisateur_id == current_user.id)
        )
    )
    session = result.scalars().first()
    if not session:
        raise HTTPException(404, "Session not found")

    exercice = await db.get(Exercice, session.exercice_id)
    reponses = session.reponses or []

    # Construire le prompt
    messages = []
    for rep in reponses:
        messages.append({"role": "user", "content": rep["texte"]})

    async def generate():
        client = anthropic.Anthropic(api_key=settings.openai_api_key)
        with client.messages.stream(
            model="claude-sonnet-4-20250514",
            max_tokens=1024,
            system=f"Tu es un recruteur qui mène un entretien pour le poste : {exercice.titre}. Pose des questions pertinentes basées sur les réponses du candidat.",
            messages=messages if messages else [{"role": "user", "content": "Commence l'entretien."}]
        ) as stream:
            for text in stream.text_stream:
                # Format SSE standard
                yield f"data: {json.dumps({'text': text})}\n\n"
        yield "data: [DONE]\n\n"

    return StreamingResponse(
        generate(),
        media_type="text/event-stream",
        headers={
            "Cache-Control": "no-cache",
            "X-Accel-Buffering": "no",   # Désactive la mise en tampon nginx
            "Connection": "keep-alive",
        }
    )
Pour Flutter mobile/Windows Dio ne supporte pas EventSource nativement. Utiliser dio.get(responseType: ResponseType.stream) et lire le stream chunk par chunk côté Flutter.
lib/features/simulation/services/simulation_service.dart — streamAI() Dart 
Stream<String> streamAIResponse(String sessionId) async* {
  final response = await _apiClient.dio.get(
    '/simulation/stream/$sessionId',
    options: Options(responseType: ResponseType.stream),
  );
  final stream = response.data.stream as Stream<List<int>>;
  await for (final chunk in stream) {
    final text = utf8.decode(chunk);
    for (final line in text.split('\n')) {
      if (line.startsWith('data: ') && !line.contains('[DONE]')) {
        final json = jsonDecode(line.substring(6));
        yield json['text'] as String;
      }
    }
  }
}
